## Что сделано

Создан Web API проект `HeroesApi`. В нём есть модель героя, вложенная модель оружия, enum вселенной, хранилище данных и контроллер с маршрутами для получения героев, поиска и демонстрации сериализации JSON.

## Маршруты

| Метод | URL | Описание |
| --- | --- | --- |
| GET | `/api/heroes` | Все герои |
| GET | `/api/heroes?universe=Marvel` | Герои Marvel |
| GET | `/api/heroes?universe=DC` | Герои DC |
| GET | `/api/heroes/{id}` | Герой по id |
| GET | `/api/heroes/demo` | Сравнение стандартного и настроенного JSON |
| GET | `/api/heroes/serialize` | Ручная сериализация и десериализация |
| GET | `/api/heroes/search?name=паук` | Поиск героя по имени |

## JSON

| Атрибут / настройка | Что делает | Пример |
| --- | --- | --- |
| `[JsonPropertyName("name")]` | Задаёт имя поля в JSON | `"name"` вместо `"Name"` |
| `[JsonIgnore]` | Скрывает поле из JSON | Внутренние заметки |
| `PropertyNamingPolicy.CamelCase` | Делает поля в camelCase | `realName` |
| `JsonStringEnumConverter` | Показывает enum строкой | `"Marvel"` вместо `0` |
| `WriteIndented = true` | Форматирует JSON с отступами | Удобно читать |

## Выводы

Сериализация превращает объект C# в JSON-строку, а десериализация выполняет обратное действие.

`[JsonIgnore]` нужен, чтобы не отдавать клиенту служебные или личные данные, например внутренние заметки, пароли или токены.

Enum удобнее отдавать строкой, потому что `"Marvel"` понятнее, чем `0`.

После настройки camelCase поля стали выглядеть как `realName` и `powerLevel`, то есть привычно для JSON и JavaScript.
